# Rain & Sunny Chinese Noodles
`npm install && npm run dev` · build: `npm run build`
- Business info, hours, links, menu, reviews, gallery: `src/data/site.js`
- Colours & fonts: `src/index.css` (`@theme` block)
- SEO: `index.html` (title, meta, JSON-LD), `public/sitemap.xml`, `public/robots.txt`. Replace domain `rainandsunnynoodles.ca` with the real one.
- Set `site.email` before launch (forms use mailto until a form service is chosen).
